# ZORO KEYBOARD PRO — نسخة موسعة

تتضمن هذه النسخة: إدخال عربي/إنجليزي، لوحة أرقام ورموز، حذف، مسافة، فاصلة ونقطة، تنفيذ إجراء لوحة المفاتيح/سطر جديد، لصق من الحافظة، تراجع/تقدم بمفاتيح المؤشر، مسح النص المحيط، شريط أدوات، تبديل الثيم الداكن/الفاتح، وإظهار/إخفاء شريط الأدوات مع حفظ التفضيلات محليًا.

## البناء
ارفع محتويات المشروع إلى GitHub وشغّل سير عمل Android APK. فعّل لوحة ZORO من إعدادات النظام ثم اخترها من محدد لوحات المفاتيح.

## حدود واضحة
هذه نسخة موسعة وليست لوحة تنبؤ لغوي كاملة: اقتراحات الكلمات الذكية، قاموس قابل للتعلم، الكتابة بالإيماءات، وتخصيص تخطيط/ألوان كامل ليست منفذة هنا. لا تدّعي النسخة جمع النصوص أو إرسالها للإنترنت.
